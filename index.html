Sobre mí

Cómo llegué al desarrollo

Soy desarrollador backend junior enfocado en Python, con experiencia práctica construyendo aplicaciones web con Django y Flask: modelado de datos, funcionalidades CRUD, integración de APIs externas y despliegue en producción. Trabajo también con HTML, CSS, JavaScript y Bootstrap para el frontend de mis proyectos.

Antes de dedicarme de lleno al desarrollo, trabajé enseñando programación — Python, JavaScript, HTML/CSS, lógica y algoritmos. Esa experiencia me dejó algo que uso todos los días como desarrollador: explicar ideas técnicas con claridad, tener paciencia para resolver problemas paso a paso, y comunicarme bien con equipos y usuarios no técnicos.

Uso Git y GitHub como parte de mi flujo de trabajo diario, y estoy en constante aprendizaje — actualmente profundizando en redes (Cisco) como conocimiento complementario. Busco una oportunidad remota en Colombia o Latinoamérica donde seguir creciendo como desarrollador backend.
